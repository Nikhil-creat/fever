System Design

Architecture

Full production stack — code lives in the repo, deploy config lives in Helm/GitHub Actions.

⚡

FastAPI application

Async execution, redis.asyncio connection pooling, Prometheus metrics middleware, K8s liveness/readiness probes with psutil memory checks.

📦

Containerization

Multi-stage Dockerfile, non-root UID 1001, slim base image, pre-built wheel layer caching.

☸️

Kubernetes / Helm

Deployment, Service, Ingress (NGINX + cert-manager TLS + rate limiting), and an HPA driven by CPU, memory, and custom Prometheus RPS metrics.

🧪

Load testing

Locust suite with synthetic job/resume generators and a step-ramp → spike traffic shape for HPA validation.

🔁

CI/CD

GitHub Actions: lint (Black/Flake8) + PyTest → build/push to GHCR → Helm upgrade with automatic rollback.

📊

Observability

Grafana dashboard (RPS, latency percentiles, cache hit ratio, pod CPU/mem), Prometheus alert rules, Alertmanager routing to Slack + PagerDuty.

Deployment Guide

Deploying the real backend

GitHub Pages only serves static files, so it can't run the FastAPI/Redis backend directly. This page is a static showcase + demo client. To make the "live" demo actually call real infrastructure: 

1. Deploy app/ + Dockerfile to any container host
   (Render, Railway, Fly.io, EC2, or the included Helm chart on a K8s cluster)
2. Enable CORS on the FastAPI app for your Pages origin
3. Paste that backend's public URL into the "Backend URL" field above
4. The demo will call /api/v1/match on your real server instead of mocking
